# 광합성에 필요한 물질과 산물 확인하기 · 가상 실험

투명 밀폐 용기 속 시금치 잎에 LED 빛을 비추고, 산소·이산화 탄소 센서로 농도 변화를 측정하는 중학교 과학 가상 탐구 실험입니다. 태블릿·컴퓨터 브라우저에서 합니다.

**바로 가기:** https://kimju1416.github.io/photosynthesis-materials/

## 1단계 · 실험 장치 구성

시금치 잎, 이산화 탄소 센서(뚜껑 왼쪽 구멍), 산소 센서(오른쪽 구멍), LED 전등을 실험대의 점선 자리에 끌어다 놓습니다. 준비물을 누른 뒤 자리를 눌러도 됩니다. 4개를 모두 설치하면 2단계로 넘어갑니다.

## 2단계 · 측정 및 분석

- 센서 전원과 LED 전등을 켜고 측정을 시작합니다.
- 측정 간격 1분, 측정 시간 10분. 화면에서는 1분을 3초로 줄여 약 30초 동안 보여 줍니다.
- 실험대 오른쪽에 그래프가 2개 있습니다. 위는 이산화 탄소(ppm), 아래는 산소(%)입니다.
- 그래프 밑 **탐구 결과 기록**에서 답을 골라 「답 확인」을 누릅니다. 칸마다 정답·오답이 표시되고, 모두 맞히면 크게 «정답입니다»가 나옵니다.
  1. 이산화 탄소 농도(높아진다 · 낮아진다 · 변화 없다), 산소 농도(높아진다 · 낮아진다 · 변화 없다)
  2. 광합성에 필요한 물질(이산화 탄소 · 산소), 광합성 산물(이산화 탄소 · 산소)

## 측정값에 대하여

교육용 모형 값입니다. 이산화 탄소는 약 1,180ppm에서 10분 동안 약 700ppm 줄고, 광합성에서 흡수한 이산화 탄소만큼(1:1) 산소가 나오므로 산소는 20.90%에서 약 0.07% 늘어납니다(1ppm = 0.0001%). 실제 측정값처럼 작은 흔들림을 넣었습니다.
